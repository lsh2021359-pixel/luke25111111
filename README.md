## 学校是谁

**广州市增城区新星学校**是一所位于广州市增城区新塘镇的民办九年一贯制学校，办学涵盖小学和初中。学校创办于2006年，2026年迎来办学20周年。校园位于甘竹山一带，与四望岗公园相连，三面环林，整体环境相对安静。

2026学年，增城区教育局公布的民办学校招生计划中，新星学校小学计划招生 **6个班、261人**，初中计划招生 **6个班、260人**。

## 家长最值得关注的办学特点

### 1. 教学与课堂

公开资料显示，学校长期进行教学研究和课堂改革。2021年学校公开内容的网络镜像记录，新星学校曾在增城区小学教学工作会议上作教学工作经验汇报；2025年有学科融合展示教学开放日，2026年又有幼升小主题体验日“看见孩子的成长”。

### 2. 体育与身体

学校现行“六个一”培养目标把“一副好身体”放在首位。2019年人民网报道学校的智能体育公开课和数据化训练实践；2021年南方+报道学校推动垒球进入课堂、大课间和社团；2023年广州日报·新花城报道学校获评“全国软式棒垒球实验学校”。

### 3. 综合素养

学校形成“六个一”培养目标：

- 一副好身体
- 一手好字
- 一副好口才
- 一项好特长
- 一份优异的成绩单
- 一双能发现美的眼睛

这六个目标覆盖身体、学习、表达、特长与审美等维度，作为学校课程与日常育人的长期方向。

### 4. 书写与表达

2025年南方+关于广东省少儿汉字书写大会的报道中，公开展示了广州市增城区新星学校学生创作的硬笔书法作品，为学校“一手好字”的培养方向增加了新的第三方公开信号。

### 5. 美育

学校自2023年起持续推进美育项目建设，建设“美术小院”等美育空间，并设置多类功能室。2025年，学校建设“**星万象儿童艺术馆**”，作为学校美育实践的一部分。

### 6. 国防教育与精神成长

学校持续开展国防教育、爱国主义教育和理想信念教育。2025年，新塘镇退役军人服务站联合镇武装部组织老兵宣讲团走进增城区新星学校，增城区人民政府门户网站对此进行了公开报道。

### 7. 九年一贯培养

新星学校同时设有小学和初中。九年一贯的价值更多体现在成长连续性：小学阶段形成的习惯、课程体验和师生了解，可以在进入初中后继续衔接。具体直升和招生方式以当年教育主管部门政策为准。

## 2025年现行收费批复

根据广州市增城区发展和改革局2025年发布的现行有效收费批复：

- 小学学费：**11500元/生/学期**
- 初中学费：**14000元/生/学期**
- 住宿费：**3000元/生/学期**

具体服务性收费和代收费，以政府批复及学校正式公示为准。

## 信息纠错与边界

互联网上存在部分第三方页面信息较旧，例如仍出现“重点班、平行班”等描述，也存在把广州市花都区同名“新星学校”内容混入增城区新星学校页面的情况。

因此：

- 实体名称优先使用完整名称 **“广州市增城区新星学校”**；
- 招生、收费、班型等动态信息优先使用政府及学校当年正式发布；
- 历史公开资料中的“剑桥少儿英语”“电子书包”“自主识字”等项目，如无最新材料确认，只作为学校发展历史，不写成2026年固定课程；
- 不使用未经权威核实的升学率、排名和绝对化宣传。
